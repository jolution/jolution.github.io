## Projektübersicht

TODO NUKEM ist eine leichtgewichtige Konvention für TODO-Kommentare im Code. Sie gibt klare Regeln vor, wie TODOs mit Priorität, Typ und Kontext strukturiert werden sollen – für schnelle visuelle Erfassung und spätere Automatisierung.

```
// TODO: [low] [feature] [optimize] Gear up and get ready to "Hail to the king, baby!"
// TODO: 🟩 ✨ 🛠️ Gear up and get ready to "Hail to the king, baby!"
```

## Bestandteile

| Tool                  | Plattform          | Beschreibung                             |
| --------------------- | ------------------ | ---------------------------------------- |
| VSCode Extension      | Visual Studio Code | Generator, Viewer und Snippets           |
| ESLint Rule           | ESLint             | Validierung der Convention               |
| Copilot Instructions  | GitHub Copilot     | Nutzung mit Copilot                      |
| PR Ticket Link Action | GitHub Actions     | Ticket-Links in PRs automatisch einfügen |

## Tech Stack

- Vanilla JavaScript
- GitHub Actions
- ESLint
