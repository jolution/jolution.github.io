## Projektübersicht

TODO NUKEM ist eine leichtgewichtige Konvention für strukturierte TODO-Kommentare im Code. Jeder Kommentar folgt dem Schema `[Priorität] [Typ] [Kontext]` – für schnelle visuelle Erfassung und einfache Automatisierung.

Das Ökosystem besteht aus mehreren Tools: Die [**VSCode Extension**](https://github.com/jolution/todo-nukem-vscode) ermöglicht das interaktive Erstellen von TODO-Kommentaren mit geführten Prompts und bietet eine Übersicht aller TODOs im Projekt mit Filteroptionen. Das [**ESLint-Plugin**](https://github.com/jolution/eslint-plugin-todo-nukem) validiert automatisch, ob Kommentare der Konvention entsprechen. Die [**Copilot Instructions**](https://github.com/jolution/todo-nukem/blob/main/.github/copilot-instructions.md#todo-comments) erlauben die Nutzung der Konvention direkt mit GitHub Copilot. Die [**GitHub Action**](https://github.com/jolution/todo-nukem-pr-ticket-link) fügt automatisch Ticket-Links in Pull-Request-Beschreibungen ein.

```
// TODO: [low] [feature] [optimize] Gear up and get ready to "Hail to the king, baby!"
// TODO: 🟩 ✨ 🛠️ Gear up and get ready to "Hail to the king, baby!"
```
