## Projektübersicht

LeCheckout for Jira ist eine Browser-Extension, die beim Öffnen eines Jira-Tickets automatisch einen passenden Git-Branch-Namen generiert. Einfach kopieren und loslegen – keine Tippfehler, keine vergessenen Präfixe.

## Features

- Direkte Integration der Jira-ID in den Branch-Namen
- Vermeidet Tippfehler und fehlende Präfixe
- Schnelles Setup per Copy & Paste
- Verfügbar für Chrome und Firefox

## Installation

Die Extension ist im <Link href="https://chromewebstore.google.com/detail/dlnckhalkgolbmdjengopemhjihfcgde" isExternal>Chrome Web Store</Link> und bei <Link href="https://addons.mozilla.org/firefox/addon/lecheckout-jira" isExternal>Firefox Add-ons</Link> verfügbar.

## Tech Stack

- JavaScript
- HTML / CSS
- Browser Extension APIs (Chrome / Firefox)
