## Project overview

TODO NUKEM is a lightweight convention for structured TODO comments in code. Each comment follows the pattern `[priority] [type] [context]` — for fast visual scanning and easy automation.

The ecosystem consists of several tools: The [**VSCode Extension**](https://github.com/jolution/todo-nukem-vscode) enables interactive TODO comment creation with guided prompts and provides a filterable overview of all TODOs in the project. The [**ESLint plugin**](https://github.com/jolution/eslint-plugin-todo-nukem) automatically validates whether comments follow the convention. The [**Copilot Instructions**](https://github.com/jolution/todo-nukem/blob/main/.github/copilot-instructions.md#todo-comments) allow using the convention directly with GitHub Copilot. The [**GitHub Action**](https://github.com/jolution/todo-nukem-pr-ticket-link) automatically adds ticket links to Pull Request descriptions.

```
// TODO: [low] [feature] [optimize] Gear up and get ready to "Hail to the king, baby!"
// TODO: 🟩 ✨ 🛠️ Gear up and get ready to "Hail to the king, baby!"
```
