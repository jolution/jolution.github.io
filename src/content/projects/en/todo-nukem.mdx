## Project overview

TODO NUKEM is a lightweight convention for TODO comments in code. It defines clear rules for structuring TODOs with priority, type, and context - for fast visual scanning and later automation.

```
// TODO: [low] [feature] [optimize] Gear up and get ready to "Hail to the king, baby!"
// TODO: 🟩 ✨ 🛠️ Gear up and get ready to "Hail to the king, baby!"
```

## Components

| Tool                  | Platform           | Description                                 |
| --------------------- | ------------------ | ------------------------------------------- |
| VSCode Extension      | Visual Studio Code | Generator, viewer, and snippets             |
| ESLint Rule           | ESLint             | Convention validation                       |
| Copilot Instructions  | GitHub Copilot     | Usage with Copilot                          |
| PR Ticket Link Action | GitHub Actions     | Automatically inserts ticket links into PRs |

## Tech stack

- Vanilla JavaScript
- GitHub Actions
- ESLint
