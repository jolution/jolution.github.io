## Project overview

LeCheckout for Jira is a browser extension that automatically generates a suitable Git branch name when you open a Jira ticket. Copy it and start immediately - no typos, no missing prefixes.

## Features

- Direct integration of the Jira ID into the branch name
- Prevents typos and missing prefixes
- Fast setup via copy and paste
- Available for Chrome and Firefox

## Installation

The extension is available in the <Link href="https://chromewebstore.google.com/detail/dlnckhalkgolbmdjengopemhjihfcgde" isExternal>Chrome Web Store</Link> and on <Link href="https://addons.mozilla.org/firefox/addon/lecheckout-jira" isExternal>Firefox Add-ons</Link>.

## Tech stack

- JavaScript
- HTML / CSS
- Browser extension APIs (Chrome / Firefox)
