## Project overview

LeCheckout is a small product cluster focused on consistent branch naming from tickets and issues.

There are currently two variants:

- **LeCheckout for Jira**: most mature and ready for daily use
- **LeCheckout for GitHub**: early alpha, still experimental

An **Azure** variant is planned.

## Version status

- **Jira version**: most stable and feature-complete variant
- **GitHub version**: strong alpha, focused on concept validation
- **Azure version**: planned

## Jira

- **Status:** most mature and closest to production use
- **Goal:** generate branch names directly from Jira tickets
- **Platforms:** Chrome and Firefox

### Features

- Direct integration of the Jira ID into the branch name
- Prevents typos and missing prefixes
- Fast setup via copy and paste
- Available for Chrome and Firefox
